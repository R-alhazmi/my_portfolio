## Overview
This project was developed as part of the **Smart Methods Training Program (July 2026)**. 

The primary objectives of this task is to designed and built a personal portfolio website, that is designed with a responsive, single-page navigation architecture using custom SCSS components to deliver a smooth user experience across all devices.

---

## Key Features

* **Hero Section:** Dynamic title, professional tagline, and quick navigation anchors.
* **About & Focus Areas:** Highlights specialization in AI architectures, relational database management, and intelligent systems.
* **Skills Matrix:** Categorized technical skill representation covering data analysis, algorithms, and web tools.
* **Projects Showcase:** Interactive card system linking directly to repository code bases.
* **Interactive Contact Form:** Clean, stateful React input interface with customized form styling.
